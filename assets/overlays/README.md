# RetroShell handheld borders

The GB, GBC, and GBA border PNGs are scaled adaptations of `GB.png`, `GBC.png`,
and `GBA.png`, the default black 1080p overlays from
[Watomsk/Overlays](https://github.com/Watomsk/Overlays), commit
`8aaf9a930c16a33df581ebd481086c29a0cb7298`.

The upstream repository does not provide a license. These PNGs therefore are
not covered by RetroShell's MIT license and should not be redistributed without
permission from their author. They are included in this local build at the
user's direction.
