# RetroShell PSP v1.0.0-beta.3

Beta 3 adds the adapter and core-package foundation, improves large-library
performance, hardens the runtime, and completes the first major interface
redesign.

## Highlights

- Native-emulator adapter SDK for PSP emulators that need the full process,
  memory, display, audio, dynarec, and suspend lifecycle.
- Protocol-v1 direct ROM launch, shared L+R+Select pause contract,
  return-to-RetroShell flow, and per-game shared save paths.
- Validated drag-and-drop `.rscore.zip` installation from `RETROSHELL/cores/`.
- Large-library rendering, sorting, cache, artwork, and navigation fixes.
- PSP-native frame paths, bounded audio recovery, ROM streaming, RTC
  persistence, suspend safety, and save/state hardening.
- Redesigned home rail, Recently Played drawer, game lists, details, settings,
  pause menu, console icons, fonts, themes, branding, and startup shimmer.
- Expanded host tests, parser fuzz smoke tests, deterministic packaging,
  provenance records, and hardware-oriented logging.

The main Beta 3 ZIP includes Gambatte, QuickNES, Snes9x 2005, PicoDrive,
gpSP, Beetle PCE Fast, and SMS Plus GX. Compatibility status varies by core;
see the [emulator directory](https://github.com/dadcapgamer/retroshellpsp/blob/v1.0.0-beta.3/docs/CORE_DIRECTORY.md).

FrogGBA and Snes9xTYL adapter source is included in the repository, but native
binary packages are not attached to this release while reproducible packaging
and hardware qualification remain pending.

## Install or update

1. Download `RetroShell-PSP-v1.0.0-beta.3.zip`.
2. Extract it to the root of the PSP Memory Stick and merge folders.
3. Start RetroShell from **Game → Memory Stick**.

Do not delete the existing `RETROSHELL` directory before updating. Merging the
release preserves saves, settings, artwork, installed cores, and user-supplied
BIOS files. Games and BIOS files are not included.
