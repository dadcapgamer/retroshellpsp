# Art Book Next for RetroShell

This optional, unofficial theme package contains PSP-sized adaptations of
system artwork and logos
from [Art Book Next for ES-DE](https://github.com/anthonycaccese/art-book-next-es-de)
by Anthony Caccese, source commit
`d772d07109701d9bd7c9fda305bfef6601105ab8`.

## Install

Extract the download at the root of the PSP Memory Stick and merge the
`RETROSHELL` folder. The installed manifest should be at:

`RETROSHELL/themes/art-book-next/theme.json`

Restart RetroShell, open **Settings → Theme**, and choose **Art Book Next**.
The theme can be removed by deleting only
`RETROSHELL/themes/art-book-next/`; RetroShell itself is unaffected.

logos were rasterized to transparent PNGs. The Art Book Next theme concept,
